ЭЛЕКТРОКОНТРОЛЬ 0.4.0 — WINDOWS-ДЕМО

1. Распакуйте ВЕСЬ архив в новую папку. Запустите ElectroReview.exe.
   Не переносите EXE отдельно от _internal и ocr. Python устанавливать не нужно.
2. Откройте PDF до 100 МБ, укажите имя проверяющего. Нажмите «Проверить лист».
   OCR выполнится при необходимости; затем откроется окно проверки.
3. Выберите цепь → «Сверить выбранную цепь». Проверьте оригинальные фрагменты,
   исправьте текст, включите нужные надписи. Проверьте параметры во вкладках.
   Неизвестное оставляйте неизвестным. Связь надписей устанавливает проверяющий.
4. Поставьте галочку подтверждения → «Утвердить и проверить».
   Не нужно заранее утверждать все строки OCR. Правила запускаются автоматически.
5. «Результаты проверки» → изучите замечания и «Не проверено».
   Закройте окно. Справа на главном экране утвердите / исключите замечания.
6. «Экспорт PDF» сохранит схему, отметки, подтверждённый текст и ведомость.

НЕОБЯЗАТЕЛЬНЫЙ ИИ: «Настроить ИИ» → адрес, модель, ключ.
В окне проверки отдельная кнопка «Отправить лист ИИ». Данные отправляются
только по этой команде; адрес и состав данных видны в окне. Ключ не сохраняется.
Ollama и модель устанавливаются отдельно. Облачному API нужны ключ и квота.
Программа без API работает локально. ИИ готовит черновики; вы сверяете оригинал.

«Расширенные инструменты» открывают прежние кнопки для ручной работы и OCR.
Жёлтый — требуется подтверждение; красный — утверждённое замечание.
6 условных проверок ПУЭ 1.7 — ограниченный набор, не полная экспертиза.
Критичность — экспертный индекс, не вероятность аварии. 100% — критичное замечание.
Восстановление соединений по линиям и детектор размытия ещё не реализованы.
Не внесённые в карточки цепи не проверены. Без достаточных данных — «Не проверено».
Изменили исходное чтение / карточку — подтвердите карточку и повторите проверку.

Проекты: %LOCALAPPDATA%\ElectroReview\projects. Старые проекты 0.2 / 0.3 открываются.
Подробности, ограничения и источники — README.md.
