ElectroReview 0.4.0 — проверки

59 тестов ядра, электротехнического модуля, черновиков и API успешно в среде разработки.
Сохранены проверки AES-128/256, PDF и правил ПУЭ.
Новые проверки: неоднозначные соседние надписи не назначаются цепи; подтверждаются
только выбранные чтения; оригинал сохраняется; неверный пакет не меняет проект;
сбой сохранения восстанавливает состояние; зависимые результаты устаревают.
API: проверка адреса, схемы ответа, типов / конечных чисел, источников параметров,
неизвестных ID, дублей; реальный запрос к локальному тестовому HTTP-серверу,
запрет перенаправлений и отсутствие ключа в проекте / содержимом запроса.

Windows workflow повторяет тесты и проверяет упакованный EXE из папки
с кириллицей и пробелами без внешнего OCR в PATH:
rus+eng, две вертикальные ориентации и координаты, AES-128/256, карточки,
правило PE, PDF-ведомость и аннотации, окна Tk, упрощённую проверку,
оригинальный фрагмент, пакетное утверждение / запуск правил, настройки ИИ.
Клиент API проверяется через локальный тестовый сервер с синтетическими
OCR-данными и JPEG. Внешний API не вызывается, реальные документы не отправляются.
Архив публикуется только после успешных проверок. Фактический результат конкретной
сборки — packaged-selftest.json в архиве. Версии зависимостей также включены.

Качество внешней / локальной ИИ-модели на реальных проектах НЕ измерено.
Графические символы, восстановление соединений по линиям, детектор размытия
и полная нормативная экспертиза НЕ реализованы.
